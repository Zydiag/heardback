# Commands

Generated by `scripts/gen-commands-doc.py` from the verb catalogue (`jv list --json`). Do not edit by hand.

Every action heardback can take is a `jv` verb. Run any of them from a terminal; add `--dry-run` to see what would happen, including the read-back a confirmed verb asks for.

- **Confirm**: *always* = read back and needs a spoken yes; *sometimes* = `jv` decides per call (for example, Enter into a pane that is not a Claude session); *no* = runs directly.
- **Effect**: what the verb does to your desktop. *unknown* verbs are treated like destructive ones.
- **Phrases** reach the verb on the fast path, without a model. `{name}` is a slot; `(x )?` is optional. Anything else goes to Claude, which can call the same verbs.
- **Voice**: *no* = terminal only; neither the fast path nor Claude can call it.
